# 9.2 Backend WebUI APIs (백엔드 WebUI API)

WebUI 백엔드 로직은 `nanobot/webui/` 아래 모듈에 있다. 이들은 `WebSocketChannel`(`nanobot/channels/websocket.py`)과 협력해, 순수 채팅을 넘어 세션 관리·설정·미디어·스킬·자동화 같은 WebUI 전용 기능을 제공한다([7.4](07.4-websocket-channel-and-webui-protocol.md)).

## 게이트웨이 서비스와 인증

- `gateway_services.py` (`GatewayServices`) — WebUI 요청을 처리하는 서비스 진입점. 런타임 제어(모델 전환, 상태 조회 등)를 노출.
- `gateway_tokens.py` — WebUI 접근 토큰 발급/검증([7.4](07.4-websocket-channel-and-webui-protocol.md)의 인증).
- `ws_http.py`, `http_utils.py` — WebSocket 핸드셰이크 위의 HTTP 요청 파싱(경로/쿼리 정규화: `parse_request_path`, `query_first`, `normalize_config_path`).

## 세션과 스레드

- `session_list_index.py` — 세션 목록 인덱스(사이드바용, `SessionManager.list_sessions`와 연동, [4.1](04.1-session-manager.md)).
- `forking.py` (`handle_webui_fork_chat`) — 특정 지점에서 세션 포크(`SessionManager.fork_session_before_user_index`).
- `thread_disk.py`, `transcript.py` — 스레드 디스크 저장/트랜스크립트 렌더링.
- `session_automations.py` — 세션별 자동화(cron/트리거) 조회([8.2](08.2-gateway-runtime-and-background-services.md)).
- `token_usage.py` — 토큰 사용량 집계 표시.
- `sidebar_state.py` — 사이드바 상태 영속화.

## 설정 API

- `settings_api.py`, `settings_routes.py` — WebUI에서 설정을 읽고/쓰는 API. `Config` 스키마([2.1](02.1-config-schema-and-loader.md))를 안전하게 노출/갱신.
- `metadata.py`, `version_check.py` — 인스턴스 메타데이터/버전 확인.
- `nanobot_features_api.py` — 기능 플래그/가용성.

## 미디어와 첨부

- `media_api.py`, `media_gateway.py` — 미디어 업로드/서빙(`get_media_dir`).
- `file_preview.py` — 파일 미리보기 생성.
- `transcription_ws.py` (`webui_transcription_event`) — 음성 입력 전사([5.2](05.2-anthropic-azure-bedrock-and-specialized-providers.md)).

## 스킬·CLI 앱·MCP 프리셋

- `skills_api.py` — 스킬 목록/상세([12](12-skills-system.md)).
- `cli_apps_api.py` (`normalize_cli_app_mentions`) — CLI 앱 멘션 정규화([6.3](06.3-cron-image-generation-and-other-tools.md)).
- `mcp_presets_api.py`, `mcp_presets_runtime.py` (`normalize_mcp_preset_mentions`) — MCP 프리셋 관리/런타임([6.2](06.2-web-search-and-mcp-tools.md)).

## 워크스페이스와 접근

- `workspaces.py` — 워크스페이스 목록/전환.
- 접근 제어는 `nanobot/security/workspace_access.py`의 스코프 시스템과 결합된다([11.2](11.2-workspace-policy-and-sandboxing.md)). 로컬 클라이언트는 Full Access, 원격은 제한 스코프를 받을 수 있다.
- `webui_allow_local_service_access`, `webui_allow_remote_package_install`(`ToolsConfig`, [2](02-configuration.md))가 로컬 서비스 접근·원격 패키지 설치 정책을 통제한다.

## 로깅

- `websocket_logging.py` (`websockets_server_logger`) — WebSocket 서버 로깅 어댑터.
