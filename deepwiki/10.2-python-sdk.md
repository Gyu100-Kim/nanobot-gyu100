# 10.2 Python SDK (파이썬 SDK)

HTTP API([10.1](10.1-api-endpoints-and-authentication.md)) 외에, nanobot을 파이썬 라이브러리로 직접 임베드할 수 있다. SDK 진입점은 `nanobot/nanobot.py`의 `Nanobot` 클래스이며, `docs/python-sdk.md`가 사용법을 문서화한다.

## 기본 사용

```python
from nanobot import Nanobot

async with Nanobot.from_config() as bot:
    result = await bot.run("What time is it in Tokyo?")
    print(result.content)
```

- `Nanobot.from_config(...)` — 설정 파일(`~/.nanobot/config.json` 또는 지정 경로)로부터 봇을 구성하는 팩토리.
- `async with ...` — 비동기 컨텍스트 매니저로 리소스(프로바이더, 워크스페이스, MCP 연결 등) 수명주기를 관리.
- `bot.run(text, ...) -> RunResult` — 한 번의 에이전트 실행. 내부적으로 `AgentLoop`/`AgentRunner`를 사용([3](03-agent-core.md)).
- `RunResult` — 실행 결과(`content`, 사용량, 도구 사용 내역 등). 러너의 `AgentRunResult`([3.2](03.2-agent-runner-and-llm-provider-interface.md))에 대응.

## 스트리밍

```python
from nanobot import STREAM_EVENT_TEXT_DELTA

async for event in bot.stream("Write a migration plan"):
    if event.type == STREAM_EVENT_TEXT_DELTA:
        print(event.delta, end="", flush=True)
```

- `bot.stream(text, ...)` — 스트리밍 이벤트를 async iterator로 반환.
- 이벤트 타입 상수(`STREAM_EVENT_TEXT_DELTA` 등)로 텍스트 델타·추론·도구 이벤트를 구분한다.
- SDK 실행은 `SDKCaptureHook`(`nanobot/agent/hook.py`)로 결과를 캡처한다([3.1](03.1-agent-loop-and-turn-state-machine.md)).

## 세션과 SDK 클라이언트

`nanobot/sdk/` 아래에 세부 클라이언트가 있다.

- `nanobot/sdk/clients.py`:
  - `SessionClient` — 세션 조회/조작.
  - `MemoryClient` — 메모리 파일 읽기/쓰기([4.2](04.2-memory-store-and-dream-system.md)).
  - `RuntimeClient` — 런타임 상태 제어(모델 전환 등).
- `nanobot/sdk/runtime.py` — 런타임 셀렉터 검증과 SDK 런타임 게이트/컨트롤러.

- 세션 키를 지정해 특정 대화를 이어갈 수 있다(기본은 SDK 전용 세션).

## API 서버와의 관계

- **API 서버**([10.1](10.1-api-endpoints-and-authentication.md)): 언어 무관, HTTP로 접근, OpenAI 클라이언트 호환.
- **파이썬 SDK**: 같은 프로세스에 임베드, 세션/메모리/런타임에 직접 접근, 스트리밍 이벤트를 세밀하게 처리.

같은 에이전트 코어를 두 방식으로 노출하는 것이며, 임베디드 자동화·스크립트에는 SDK가, 다국어/원격 통합에는 API 서버가 적합하다.

### 참조 파일

- `nanobot/nanobot.py` (`Nanobot`, `RunResult`, 이벤트 상수)
- `nanobot/sdk/clients.py` (`SessionClient`, `MemoryClient`, `RuntimeClient`)
- `nanobot/sdk/runtime.py`
- `nanobot/agent/hook.py` (`SDKCaptureHook`)
