# 6.2 Web, Search, and MCP Tools (웹·검색·MCP 도구)

## 웹 도구 (`nanobot/agent/tools/web.py`)

웹 도구는 두 가지다.

- `WebSearchTool` (`web_search`) — 검색 프로바이더 어댑터를 통해 웹 검색. 여러 백엔드(예: 검색 API)를 설정으로 선택.
- `WebFetchTool` (`web_fetch`) — URL을 가져와 본문을 추출.

설정 클래스(`tools.web`):

- `WebToolsConfig` — 상위 웹 설정.
- `WebSearchConfig` — 검색 프로바이더/키/파라미터.
- `WebFetchConfig` — fetch 옵션(타임아웃, 최대 크기, 리다이렉트 정책).

### SSRF 방어

웹 도구는 모든 요청을 SSRF 가드로 통과시킨다([11.1](11.1-network-security-and-ssrf-guard.md)).

- URL 안전 해석: `nanobot/security/network.py`의 타깃 검증 함수로 내부/사설 주소를 차단.
- DNS 핀닝: 해석된 IP를 고정해 리다이렉트/재해석을 통한 우회를 막는다(pinned DNS transport).
- 리다이렉트마다 대상 IP를 재검증한다.
- `tools.ssrfWhitelist`(CIDR 목록)로 예외를 둘 수 있다(예: Tailscale).

SSRF 위반은 러너에서 부드럽게 처리되어 모델에 안전한 오류로 전달된다(`AgentRunner._is_ssrf_violation`, `_ssrf_soft_payload`).

## MCP 도구 (`nanobot/agent/tools/mcp.py`)

MCP(Model Context Protocol) 서버는 외부 도구/리소스/프롬프트를 표준 프로토콜로 노출한다. nanobot은 이를 동적으로 래핑해 일반 도구처럼 쓴다.

### 설정

`tools.mcpServers`는 `dict[str, MCPServerConfig]`이다(`nanobot/config/schema.py`).

- `type`: `stdio | sse | streamableHttp`(생략 시 자동 감지).
- stdio: `command`, `args`, `env`, `cwd`.
- HTTP/SSE: `url`, `headers`.
- `toolTimeout`(기본 30초), `enabledTools`(기본 `["*"]` = 모든 capability; 제한 시 나열된 도구만, 리소스/프롬프트 제외).

### 연결과 래핑

- `AgentLoop._connect_mcp()` / `context.connect_mcp(state, tools)`가 설정된 서버에 연결([3.1](03.1-agent-loop-and-turn-state-machine.md), [3.3](03.3-context-builder-and-system-prompts.md)).
- `MCPToolWrapper` — MCP 도구를 `Tool` 인터페이스로 래핑. 이름은 `mcp_<server>_<tool>` 규약으로 정규화(`enabledTools`는 원시 이름과 래핑 이름을 모두 허용).
- `MCPResourceWrapper` — MCP 리소스를 도구로 노출.
- 스키마 정규화: MCP JSON schema를 nanobot `Schema`로 변환.
- URL 검증: HTTP MCP 엔드포인트도 SSRF 가드를 거친다.
- 일시 오류 처리: 연결/호출 실패 시 재시도·타임아웃(`toolTimeout`) 적용.

MCP 도구는 turn 시작 시 연결되고, 종료 시 `AgentLoop.close_mcp()`로 정리된다.
