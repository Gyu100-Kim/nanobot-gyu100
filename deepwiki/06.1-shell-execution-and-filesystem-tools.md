# 6.1 Shell Execution and Filesystem Tools (Shell 실행과 파일시스템 도구)

## Shell 실행 (`nanobot/agent/tools/shell.py`)

`ExecTool`은 에이전트가 셸 명령을 실행하게 해주는 도구다. `ExecToolConfig`로 설정한다(`tools.exec`).

- `execute(command, ...)` — 명령을 실행하고 stdout/stderr/exit code를 `ToolResult`로 반환. `max_tool_result_chars` 상한을 적용해 긴 출력을 자른다.
- 경로 처리: 작업 디렉토리 해석은 워크스페이스 경계 정책(`nanobot/security/workspace_policy.py`)을 따른다([11.2](11.2-workspace-policy-and-sandboxing.md)).
- 샌드박스 래핑: `nanobot/agent/tools/sandbox.py`가 플랫폼별 샌드박스 백엔드(예: Linux의 bubblewrap 등)를 감지·적용한다. `workspace_sandbox_status(...)`가 워크스페이스 제한(`restrict_to_workspace`) 상태를 계산한다.
- 명령 가드: 위험/차단 패턴 검사와 프로세스 정리(종료 시 자식 프로세스 kill).
- 지속 세션: `exec_session.py`가 상태를 유지하는 셸 세션(반복 명령 간 cwd/env 유지)을 지원한다.

## 파일시스템 도구 (`nanobot/agent/tools/filesystem.py`)

파일 도구는 공통 베이스 `_FsTool`(경로 해석·검증)에서 파생된다.

| 도구 | 클래스 | 역할 |
|---|---|---|
| `read_file` | `ReadFileTool` | 파일/문서 읽기(텍스트·일부 바이너리 문서) |
| `write_file` | `WriteFileTool` | 새 파일 쓰기/덮어쓰기 |
| `edit_file` | `EditFileTool` | 기존 파일의 부분 편집(문자열 치환) |

- 경로 해석은 `nanobot/agent/tools/path_utils.py`와 워크스페이스 정책을 사용해 워크스페이스 밖 접근을 통제한다.
- 파일 상태 추적: `file_state.py`의 `FileStates`가 읽은/쓴 파일 상태를 기록해, 편집 전 읽기 강제 같은 정합성 검사를 지원한다.
- 대용량/문서 처리: 콘텐츠 크기 상한과 문서 파싱 로직을 포함.

## 검색 도구 (`nanobot/agent/tools/search.py`)

- `FindFilesTool` (`find_files`) — 이름/글롭 패턴으로 파일 검색.
- `GrepTool` (`grep`) — 정규식으로 파일 내용 검색.

두 도구 모두 워크스페이스 경계를 존중하며 읽기 전용(`read_only=True`)이라 병렬 실행에 안전하다.

## 패치 적용 (`nanobot/agent/tools/apply_patch.py`)

`apply_patch`는 통합 diff 형태의 패치를 적용하는 도구로, 여러 파일을 한 번에 수정할 때 사용한다.

## 파일 상태와 정합성 (`file_state.py`)

`FileStates`는 세션 동안 어떤 파일을 읽고 썼는지 추적한다. 이는 "편집 전에 반드시 읽어야 한다"는 계약을 강제해, 모델이 오래된 내용을 근거로 잘못 덮어쓰는 것을 방지한다.
