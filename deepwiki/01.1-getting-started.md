# 1.1 Getting Started (시작하기)

## 설치

nanobot은 `nanobot-ai` 패키지로 배포된다(`pyproject.toml`의 `[project].name`). 요구 파이썬은 `>=3.11`.

```bash
python -m pip install nanobot-ai
```

설치하면 `nanobot` CLI가 등록된다(`[project.scripts]`의 `nanobot = "nanobot.cli.commands:app"`). CLI는 `nanobot/cli/commands.py`의 Typer 앱(`app`)이 구현한다.

## 초기 설정 (onboard)

첫 실행은 온보딩 마법사로 시작한다.

```bash
nanobot onboard
```

`onboard` 명령은 `nanobot/cli/commands.py`의 `onboard()` 함수가 진입점이며, 실제 대화형 마법사는 `nanobot/cli/onboard.py`에 구현되어 있다. 프로바이더 선택, API 키 입력, 모델 프리셋 구성 등을 안내한다(`_configure_model_presets`, `_handle_provider_field`, `_input_model_with_autocomplete` 등).

설정은 기본적으로 `~/.nanobot/config.json`에, 워크스페이스는 `~/.nanobot/workspace/`에 저장된다(`nanobot/config/paths.py`의 `get_config_path`, `get_workspace_path`).

## 첫 대화 확인

설정이 끝나면 아래 명령으로 프로바이더/모델/워크스페이스 접근이 정상인지 확인한다. 이 검증은 모든 배포·디버깅의 출발점이다.

```bash
nanobot status          # config/workspace/model/provider 요약
nanobot agent -m "Hello!"   # 실제 메시지 한 건
```

`nanobot agent -m "..."`는 인바운드 메시지 하나를 에이전트 루프에 넣고 답변을 터미널에 출력한다. 정상 답변이 나오면 install, config, provider/model 선택, 워크스페이스 쓰기가 모두 사용 가능한 상태다.

대화형 모드는 인자 없이 실행한다.

```bash
nanobot agent           # 세션 히스토리가 유지되는 터미널 채팅
```

## 장기 실행 (Gateway / WebUI)

채팅 앱, WebUI, heartbeat, Dream, cron 같은 상시 기능은 게이트웨이로 띄운다.

```bash
nanobot gateway         # 채널·백그라운드 서비스 실행
nanobot webui           # WebUI 준비 후 브라우저 오픈
```

`nanobot webui`는 config/workspace를 필요 시 생성하고, 프로바이더 설정을 점검하고, 로컬 WebSocket 채널을 켠 뒤 게이트웨이를 시작하고 브라우저를 연다(`docs/webui.md`). WebUI는 WebSocket 채널이 포트 `8765`에서 서빙하며, 게이트웨이 health 엔드포인트(`18790`)와 다르다.

## 여러 인스턴스 실행

`--config`/`--workspace` 플래그로 인스턴스를 분리할 수 있다.

```bash
nanobot onboard --config ./bot-a/config.json --workspace ./bot-a/workspace
nanobot agent  --config ./bot-a/config.json --workspace ./bot-a/workspace -m "Hi"
nanobot gateway --config ./bot-a/config.json --workspace ./bot-a/workspace
```

config는 nanobot이 무엇을 쓸 수 있는지 통제하고, workspace는 그 인스턴스의 상태(메모리, 세션, cron, 스킬, 산출물)를 보관한다.

## 개발 환경

레포 소스에서 작업할 때 자주 쓰는 명령은 `AGENTS.md`에 정리되어 있다.

```bash
pytest tests/test_openai_api.py::test_function -v   # 단일 테스트
ruff check nanobot/                                  # 파이썬 린트

cd webui && bun run dev      # WebUI 개발 서버(게이트웨이 :8765 프록시)
cd webui && bun run build    # ../nanobot/web/dist 로 빌드(휠에 번들)
cd webui && bun run test     # WebUI 테스트
```
