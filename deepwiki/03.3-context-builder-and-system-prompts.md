# 3.3 Context Builder and System Prompts (컨텍스트 빌더와 시스템 프롬프트)

`nanobot/agent/context.py`의 `ContextBuilder`는 각 턴에서 모델에 보낼 시스템 프롬프트와 메시지 배열을 조립한다.

## 생성

```python
ContextBuilder(workspace: Path, timezone: str | None = None,
               disabled_skills: list[str] | None = None)
```

- `workspace` — 부트스트랩 파일(SOUL/USER/MEMORY 등)과 스킬을 읽는 기준.
- `timezone` — 런타임 컨텍스트의 시간 표기.
- `disabled_skills` — 로딩에서 제외할 스킬(`agents.defaults.disabledSkills`).

## 시스템 프롬프트

`build_system_prompt(...)`가 시스템 프롬프트를 만든다. 구성 요소:

- **아이덴티티** — `_get_identity(channel, workspace)`. 워크스페이스의 `SOUL.md` 또는 템플릿 `nanobot/templates/agent/identity.md`, `nanobot/templates/SOUL.md`에서 로드.
- **부트스트랩 파일** — `_load_bootstrap_files(workspace)`. `SOUL.md`, `USER.md`, `memory/MEMORY.md` 등 장기 지식 파일을 합침. `_is_template_content`로 아직 사용자가 커스터마이즈하지 않은 순수 템플릿인지 판별.
- **스킬 섹션** — `SkillsLoader`(`nanobot/agent/skills.py`)가 만든 요약/본문. 항상 로드되는 스킬(`get_always_skills`, 예: `memory`, `my`)과 요청 관련 스킬을 포함([12. Skills System](12-skills-system.md)).
- **런타임 컨텍스트** — `_build_runtime_context(...)` 및 모듈 함수 `runtime_lines(state, msg, workspace)`. 현재 모델, 반복 한계, 워크스페이스 경로, 시간대, 목표 상태 등을 요약(`nanobot/session/goal_state.py`의 `goal_state_runtime_lines`).
- **도구 계약/플랫폼 정책** — 템플릿 `nanobot/templates/agent/tool_contract.md`, `platform_policy.md`.

프롬프트 템플릿은 `nanobot/templates/agent/` 아래에 마크다운으로 있고 Jinja2로 렌더링된다(`nanobot/utils/prompt_templates.py`). 주요 템플릿:

| 파일 | 용도 |
|---|---|
| `identity.md` | 기본 아이덴티티 |
| `skills_section.md` | 스킬 섹션 |
| `tool_contract.md` | 도구 사용 계약 |
| `platform_policy.md` | 플랫폼별 정책 |
| `dream.md` | Dream 프롬프트([4.2](04.2-memory-store-and-dream-system.md)) |
| `consolidator_archive.md` | 컨솔리데이터 아카이브([4.3](04.3-consolidation-and-autocompact.md)) |
| `subagent_system.md`, `subagent_announce.md` | 서브에이전트([3.4](03.4-sub-agents-and-parallel-execution.md)) |
| `cron_reminder.md` | cron 리마인더 |
| `max_iterations_message.md` | 반복 한계 메시지 |
| `evaluator.md` | 평가자 |

## 메시지 빌드

`build_messages(...)`는 시스템 프롬프트 + 세션 히스토리 + 현재 사용자 메시지를 OpenAI 스타일 배열로 만든다.

- `_build_user_content(text, media)` — 텍스트/미디어(이미지 등)를 멀티모달 content 블록으로 변환.
- `_merge_message_content(left, right)` — content 병합.
- 히스토리는 `Session.get_history(...)`로부터 오며 토큰 예산에 맞춰 재생된다([4.1](04.1-session-manager.md)).

## MCP·런타임 제어 헬퍼

모듈 수준 함수:

- `connect_mcp(state, tools)` — MCP 도구 연결.
- `handle_runtime_control(state, msg, tools)` — 런타임 제어 메시지 처리.
- `session_extra(metadata)` — 세션 메타데이터에서 추가 컨텍스트 추출.
