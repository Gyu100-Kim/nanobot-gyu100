# 2.2 Providers and Model Presets (프로바이더와 모델 프리셋)

## 프로바이더 레지스트리 (`nanobot/providers/registry.py`)

프로바이더 메타데이터의 단일 출처는 `PROVIDERS` 리스트다. 각 항목은 `ProviderSpec`(frozen dataclass)이며, 이 하나의 파일에서 환경 변수, config 매칭, 상태 표시가 모두 파생된다.

새 프로바이더 추가는 두 단계다(파일 상단 주석).

1. `PROVIDERS`에 `ProviderSpec` 추가.
2. `nanobot/config/schema.py`의 `ProvidersConfig`에 필드 추가.

### `ProviderSpec` 주요 필드

| 필드 | 의미 |
|---|---|
| `name` | config 필드 이름(예 `dashscope`) |
| `keywords` | 모델 이름 매칭용 키워드(소문자) |
| `env_key` | API 키 환경 변수(예 `DASHSCOPE_API_KEY`) |
| `display_name`, `model_catalog` | 상태 표시/WebUI 모델 목록 소스 |
| `backend` | 구현 선택: `openai_compat`(기본), `anthropic`, `azure_openai`, `openai_codex`, `github_copilot`, `bedrock` |
| `env_extras`, `default_extra_headers` | 추가 env/헤더(`{api_key}`, `{api_base}` 치환) |
| `is_gateway` | 여러 모델 패밀리를 라우팅(OpenRouter, AiHubMix) |
| `is_local` | 로컬 배포(vLLM, Ollama) |
| `detect_by_key_prefix`, `detect_by_base_keyword`, `default_api_base` | 자동 감지 힌트 |
| `strip_model_prefix(es)` | 게이트웨이 전송 전 `provider/` 접두 제거 |
| `is_oauth`, `is_direct`, `is_transcription_only` | 특수 흐름 |
| `supports_prompt_caching` | Anthropic 프롬프트 캐싱 등 |
| `thinking_style`, `gateway_reasoning_style`, `reasoning_as_content`, `reasoning_effort_remap`, `implicit_reasoning_models`, `extract_thinking_blocks`, `strip_history_reasoning_content` | 추론/thinking 제어 |

리스트 순서가 매칭 우선순위와 폴백을 결정한다(게이트웨이 우선). 헬퍼: `find_by_name(name)`, `create_dynamic_spec(name, thinking_style=...)`.

### 내장 프로바이더(발췌)

`custom`, `azure_openai`, `bedrock`, `openrouter`, `opencode`/`opencode_zen`/`opencode_go`, `huggingface`, `skywork`, `aihubmix`, `siliconflow`, `novita`, `volcengine`(+`coding_plan`), `byteplus`(+`coding_plan`), `anthropic`, `openai`, `openai_codex`, `github_copilot`, `deepseek`, `gemini`, `zhipu`, `dashscope`, `moonshot`, `kimi_coding`, `minimax`(+`minimax_anthropic`), `mistral`, `stepfun` 등. 로컬로는 `vllm`, `ollama`, `lm_studio`, `atomic_chat`, `ovms`.

## 프로바이더 설정 (`ProvidersConfig`)

각 프로바이더는 `ProviderConfig`로 설정한다(`nanobot/config/schema.py`).

- `apiKey`, `apiBase`, `apiType`(`auto|chat_completions|responses`), `extraHeaders`, `extraBody`, `extraQuery`, `proxy`, `thinkingStyle`.
- `BedrockProviderConfig`는 추가로 `region`, `profile`을 가진다.

`extra="allow"`이므로 스키마에 없는 임의 키를 커스텀 OpenAI 호환 프로바이더로 추가할 수 있다.

## 모델 프리셋 (Model Presets)

프리셋은 모델과 생성 파라미터를 이름으로 묶은 것이다(`ModelPresetConfig`). 활성 프리셋은 `agents.defaults.modelPreset`으로 고른다.

```json
{
  "modelPresets": {
    "primary": {
      "provider": "openrouter",
      "model": "anthropic/claude-opus-4.5"
    }
  },
  "agents": { "defaults": { "modelPreset": "primary" } }
}
```

- `default`는 예약어라 `modelPresets` 키로 못 쓴다. `agents.defaults` 필드가 암묵적 `default` 프리셋이 된다.
- 프로바이더 해석 순서(`docs/concepts.md`):
  1. 프리셋/암묵 default의 provider가 `"auto"`가 아니면 그것을 사용.
  2. `"auto"`면 모델 이름·API 키·로컬 base URL·게이트웨이 프로바이더로 추론(`Config._match_provider`).
  3. OpenAI Codex, GitHub Copilot 등 OAuth 프로바이더는 명시적 로그인과 명시적 provider/model이 필요.

처음 설정할 때는 프리셋 안에서 provider를 고정하는 편이 디버깅에 유리하다.

## 프로바이더 스냅샷과 팩토리

런타임에서 프리셋은 `ProviderSnapshot`으로 변환된다(`nanobot/providers/factory.py`). 관련 헬퍼:

- `make_provider(...)`: 설정으로부터 실제 `LLMProvider` 인스턴스 생성.
- `build_provider_snapshot`, `load_provider_snapshot`, `provider_signature`: 스냅샷 빌드/캐시 무효화용 시그니처.
- `_resolve_fallback_presets`, `_inline_fallback_preset`: 폴백 체인 구성 → `FallbackProvider`로 감쌈([5.2](05.2-anthropic-azure-bedrock-and-specialized-providers.md)).
- `nanobot/agent/model_presets.py`: `configured_model_presets`, `build_static_preset_snapshot`, `build_runtime_preset_snapshot`, `normalize_preset_name`.
