# 10.1 API Endpoints and Authentication (API 엔드포인트와 인증)

`nanobot/api/server.py`는 OpenAI 호환 HTTP 엔드포인트를 `aiohttp`로 구현한다.

## `GET /health`

`handle_health`가 처리한다. 서버 가동 여부를 확인하는 단순 헬스 체크로, 인증이 필요 없다.

## `GET /v1/models`

`handle_models`가 처리한다. 사용 가능한 모델(설정된 모델 프리셋, [2.2](02.2-providers-and-model-presets.md))을 OpenAI `models` 응답 형식으로 반환한다.

## `POST /v1/chat/completions`

`handle_chat_completions`가 핵심 엔드포인트다. OpenAI Chat Completions 요청을 받아 에이전트 턴을 실행하고 응답을 돌려준다.

### 요청 파싱

- JSON 본문과 multipart(파일 첨부) 둘 다 파싱한다.
- 이미지/파일은 base64 data URL로 오며 `_save_base64_data_url`로 저장한다(`MAX_FILE_SIZE`, `_FileSizeExceeded` 제한).
- `messages` 배열을 인바운드 메시지로 변환해 에이전트 루프에 넣는다.

### 응답

- 비스트리밍: `_chat_completion_response(...)`가 표준 chat completion JSON을 만든다.
- 스트리밍(`stream: true`): `_sse_chunk(...)`로 SSE(`text/event-stream`) 델타를 전송하고 `[DONE]`으로 종료.
- 오류: `_error_json(...)`가 OpenAI 오류 형식으로 반환.
- 빈 최종 응답은 `EMPTY_FINAL_RESPONSE_MESSAGE`로 대체.

### 세션

기본은 고정 세션(`api:default`)이지만, 요청에서 세션 ID를 지정하면 별도 세션으로 라우팅된다. 이로써 여러 대화를 분리할 수 있다(`docs/openai-api.md`).

## 인증

`create_app(...)`이 붙이는 미들웨어가 인증을 처리한다.

- **로컬 vs 네트워크**: 로컬(loopback) 접근과 원격 접근을 구분한다. `host`가 loopback이면 완화된 정책, `0.0.0.0`/`::`이면 `apiKey`가 필수([2.1](02.1-config-schema-and-loader.md)).
- **Bearer 토큰**: 원격 요청은 `Authorization: Bearer <apiKey>`를 요구한다. 비교는 `hmac`으로 상수 시간 수행해 타이밍 공격을 방지한다.

## 클라이언트 예시

OpenAI 파이썬 클라이언트를 그대로 쓸 수 있다.

```python
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8900/v1", api_key="<apiKey>")
resp = client.chat.completions.create(
    model="default",
    messages=[{"role": "user", "content": "안녕?"}],
)
print(resp.choices[0].message.content)
```

프로그래밍 방식 사용의 또 다른 경로는 파이썬 SDK다([10.2](10.2-python-sdk.md)).
