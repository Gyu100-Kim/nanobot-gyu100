# 5.2 Anthropic, Azure, Bedrock, and Specialized Providers (Anthropic·Azure·Bedrock·특수 프로바이더)

OpenAI 호환 계층([5.1](05.1-openai-compatible-provider.md)) 외에도, 서로 다른 wire 포맷을 가진 백엔드를 위한 전용 프로바이더가 있다.

## AnthropicProvider (`anthropic_provider.py`)

Anthropic Messages API를 사용하는 프로바이더다. `anthropic` SDK를 감싼다.

- 메시지 변환: `_convert_messages(...)` — OpenAI 스타일 메시지를 Anthropic 포맷(system 분리, `content` 블록)으로 변환.
- 도구 변환: `_convert_tools(...)` — 도구 스키마를 Anthropic `tools` 포맷으로.
- 이미지 변환: `_convert_image(...)` — 이미지 블록을 Anthropic `image` source 포맷으로.
- 스트리밍: `chat_stream` 구현에서 Anthropic 이벤트를 델타/추론 블록으로 파싱. thinking 블록(extended thinking)을 추론으로 노출.
- 응답 파싱: `_parse_response(...)` → `LLMResponse`, 도구 호출 추출.
- 프롬프트 캐싱: `supports_prompt_caching` 프로바이더에서 `cache_control` 마커 적용.

`kimi_coding`, `minimax_anthropic` 등 일부 프로바이더는 Anthropic Messages API를 사용하므로 이 백엔드를 공유한다(`ProviderSpec.backend == "anthropic"`).

## AzureOpenAIProvider (`azure_openai_provider.py`)

Azure OpenAI 배포를 위한 프로바이더다. 모델 이름이 **배포 이름(deployment name)**으로 취급되며, `api-version` 쿼리와 엔드포인트 규약이 표준 OpenAI와 다르다. `azure_openai` config 필드(`ProviderConfig`)의 `apiBase`, `apiVersion`(via `extraQuery`)을 사용한다. `[project.optional-dependencies].azure` extra가 필요하다.

## BedrockProvider (`bedrock_provider.py`)

AWS Bedrock Converse API를 사용한다. `BedrockProviderConfig`(`region`, `profile`)로 설정하며, `AWS_REGION`/`AWS_DEFAULT_REGION`/프로파일로 폴백한다. `bedrock` extra(boto3 등)가 필요하다.

## OAuth 프로바이더

두 프로바이더는 API 키가 아니라 OAuth 로그인으로 인증한다. 그래서 `ProvidersConfig`에서 `exclude=True`로 직렬화에서 제외된다(자격증명을 config.json에 저장하지 않음).

- **OpenAICodexProvider** (`openai_codex_provider.py`) — OpenAI Codex. `is_oauth=True`.
- **GithubCopilotProvider** (`github_copilot_provider.py`) — GitHub Copilot.

이들은 명시적 로그인과 명시적 provider/model 선택이 필요하다([2.2](02.2-providers-and-model-presets.md)).

## FallbackProvider (`fallback_provider.py`)

`FallbackProvider`는 다른 프로바이더들을 감싸 프라이머리 실패 시 순차적으로 대체 모델로 재시도한다.

- `agents.defaults.fallbackModels`(문자열 프리셋 이름 또는 인라인 후보)로 구성.
- 팩토리의 `_resolve_fallback_presets`, `_inline_fallback_preset`가 후보 프리셋을 프로바이더로 만들어 체인을 구성([2.2](02.2-providers-and-model-presets.md)).
- 프라이머리 프로바이더가 재시도 불가 오류(인증 실패 등)나 소진 시 다음 후보로 넘어간다.

## 특수 프로바이더

- **이미지 생성** (`image_generation.py`): `ImageGenerationProvider(ABC)` 아래 OpenRouter, AiHubMix, Ollama, Gemini, MiniMax 등 클라이언트. `image_generation` 도구가 사용([6.3](06.3-cron-image-generation-and-other-tools.md)).
- **음성 전사** (`transcription.py`): AssemblyAI, OpenAI, Groq, OpenRouter, Xiaomi MiMo, StepFun 어댑터. 채널이 받은 오디오를 텍스트로 변환(`transcription` config, `TranscriptionConfig`).
