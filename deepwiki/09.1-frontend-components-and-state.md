# 9.1 Frontend Components and State (프론트엔드 컴포넌트와 상태)

WebUI 프론트엔드는 `webui/src/` 아래의 React + TypeScript 코드다. 빌드는 Vite, 패키지 매니저는 Bun을 쓴다.

## 진입점과 스크립트

- `webui/src/main.tsx` — 앱 부트스트랩.
- `webui/src/App.tsx` — 최상위 컴포넌트, 레이아웃과 라우팅.
- `webui/package.json` 스크립트:
  ```json
  {
    "dev": "vite",
    "build": "tsc -p tsconfig.build.json && vite build",
    "preview": "vite preview",
    "test": "vitest run",
    "test:watch": "vitest",
    "lint": "eslint src --max-warnings 0"
  }
  ```

## 주요 컴포넌트 (`webui/src/components/`)

| 컴포넌트 | 역할 |
|---|---|
| `Sidebar.tsx` | 세션 목록/네비게이션 |
| `ChatList.tsx` | 채팅 메시지 리스트 |
| `MessageBubble.tsx` | 개별 메시지 버블(사용자/어시스턴트) |
| `MarkdownText.tsx`, `MarkdownTextRenderer.tsx` | Markdown 렌더링 |
| `CodeBlock.tsx` | 코드 블록(하이라이트) |
| `ConnectionBadge.tsx` | WebSocket 연결 상태 표시 |
| `AttachmentTile.tsx`, `FilePreviewPanel.tsx`, `ImageLightbox.tsx`, `FileReferenceChip.tsx` | 첨부/파일 미리보기 |
| `SessionSearchDialog.tsx`, `RenameChatDialog.tsx`, `DeleteConfirm.tsx` | 세션 관리 다이얼로그 |
| `CliAppMentionText.tsx` | CLI 앱 멘션 렌더링 |
| `LanguageSwitcher.tsx` | 다국어 전환(`webui/src/i18n`) |
| `settings/`, `thread/`, `ui/` | 설정 패널, 스레드 활동, UI 프리미티브 |

## 상태 훅 (`webui/src/hooks/`)

React 훅으로 상태와 부수효과를 관리한다.

| 훅 | 역할 |
|---|---|
| `useNanobotStream.ts` | WebSocket 스트림 구독, 델타/이벤트 수신([7.4](07.4-websocket-channel-and-webui-protocol.md)) |
| `useSessions.ts` | 세션 목록/선택/생성/삭제 |
| `useSessionAutomationJobs.ts` | 세션별 자동화(cron/트리거) 조회([8.2](08.2-gateway-runtime-and-background-services.md)) |
| `useSkills.ts` | 스킬 목록([12](12-skills-system.md)) |
| `useSidebarState.ts` | 사이드바 열림/접힘 상태 |
| `useAttachedImages.ts`, `useClipboardAndDrop.ts` | 첨부 이미지/붙여넣기·드롭 |
| `useVoiceRecorder.ts` | 음성 녹음(전사 입력) |
| `useTheme.ts` | 테마(다크/라이트) |
| `useDeferredTitleRefresh.ts` | 세션 제목 지연 갱신 |

## 클라이언트 라이브러리 (`webui/src/lib/`)

- `nanobot-client.ts` — WebSocket 클라이언트(연결/재연결/프레임 송수신).
- `api.ts`, `http.ts` — HTTP API 래퍼([9.2](09.2-backend-webui-apis.md)).
- `types.ts` — 공유 타입 정의.
- `runtime.ts`, `workspace.ts` — 런타임/워크스페이스 상태 헬퍼.
- `activity-timeline.ts`, `tool-traces.ts`, `subagent-channel-display.ts` — 도구 실행/서브에이전트 활동 포맷팅.
- `cli-app-events.ts`, `mcp-preset-events.ts` — CLI 앱/MCP 프리셋 이벤트.
- `media.ts`, `imageEncode.ts` — 미디어 인코딩/디코딩.
- `format.ts`, `ansi.ts`, `remark-tex-math.ts`, `utils.ts` — 렌더링 유틸.
