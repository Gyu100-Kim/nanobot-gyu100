# 8.1 CLI Commands Reference (CLI 명령 레퍼런스)

CLI 명령은 두 층위로 나뉜다: 셸에서 실행하는 **Typer 명령**(`nanobot/cli/commands.py`)과, 대화 중 입력하는 **슬래시 명령**(`nanobot/command/`).

## Typer 셸 명령

| 명령 | 함수 | 역할 |
|---|---|---|
| `nanobot onboard` | `onboard` | 대화형 초기 설정 마법사([1.1](01.1-getting-started.md)) |
| `nanobot agent [-m ...]` | `agent` | 일회성/대화형 에이전트 실행 |
| `nanobot serve` | `serve` | OpenAI 호환 API 서버 실행([10](10-openai-compatible-api-server.md)) |
| `nanobot webui` | `webui` | WebUI 준비·게이트웨이 시작·브라우저 오픈([9](09-webui.md)) |
| `nanobot trigger <id> "<msg>"` | `trigger` | 외부에서 로컬 트리거 발화 |
| `nanobot status` | `status` | config/workspace/model/provider 요약 |

### 서브그룹

- `nanobot gateway ...` — 게이트웨이 실행과 서비스 관리([8.2](08.2-gateway-runtime-and-background-services.md)). `status`, `logs`, `stop`, `restart`, `install-service`, `uninstall-service`.
- `nanobot channels status|login` — 채널 상태/로그인.
- `nanobot plugins list|enable|disable` — 플러그인 관리.
- `nanobot provider login|logout` — OpenAI Codex/GitHub Copilot 등 OAuth 프로바이더 로그인([2.2](02.2-providers-and-model-presets.md)).

전역 옵션: `--version`/`-v`, `--config`, `--workspace`.

## 슬래시 명령 (대화 중)

대화 중에는 슬래시 명령으로 런타임을 제어한다. 라우팅은 `nanobot/command/router.py`의 `CommandRouter`가, 핸들러는 `nanobot/command/builtin.py`가 담당한다.

| 명령 | 핸들러 | 역할 |
|---|---|---|
| `/stop` | `cmd_stop` | 현재 실행/서브에이전트 중단 |
| `/restart` | `cmd_restart` | 게이트웨이 재시작 |
| `/status` | `cmd_status` | 런타임 상태 |
| `/new` | `cmd_new` | 새 세션 시작 |
| `/model [name]` | `cmd_model` | 모델 프리셋 조회/전환([3.1](03.1-agent-loop-and-turn-state-machine.md)) |
| `/history` | `cmd_history` | 세션 히스토리 조회 |
| `/goal` | `cmd_goal` | 장기 목표 상태([4.1](04.1-session-manager.md)) |
| `/trigger` | `cmd_trigger` | 로컬 트리거 관리 |
| `/dream` | `cmd_dream` | Dream 통합 즉시 실행([4.2](04.2-memory-store-and-dream-system.md)) |
| `/dream-log` | `cmd_dream_log` | Dream 변경 이력 |
| `/dream-restore` | `cmd_dream_restore` | 이전 메모리 상태 복원 |
| `/dream-prompt` | `cmd_dream_prompt` | Dream 프롬프트 조회/설정 |
| `/pairing` | `cmd_pairing` | DM 페어링 코드 관리 |
| `/skill` | `cmd_skill` | 스킬 조회([12](12-skills-system.md)) |
| `/help` | `cmd_help` | 도움말 |

## 명령 라우터 (`nanobot/command/router.py`)

- `normalize_command_text(text)` — 입력 정규화.
- `CommandContext` — 핸들러에 전달되는 실행 컨텍스트(세션, 채널, 루프 참조 등).
- `CommandRouter` — 우선순위/정확일치/접두 매칭으로 디스패치.
  - `priority(cmd, handler)` — 최우선(예: `/stop`, `/restart`, `/status`).
  - `exact(cmd, handler)` — 정확 일치(예: `/new`).
  - `prefix(cmd_prefix, handler)` — 인자가 붙는 명령(예: `/model `).
- `register_builtin_commands(router)` — 위 매핑을 등록.

슬래시 명령은 `AgentLoop`의 COMMAND 상태에서 인라인 처리된다(`_dispatch_command_inline`, [3.1](03.1-agent-loop-and-turn-state-machine.md)).

### 참조 파일

- `nanobot/cli/commands.py` (Typer 명령)
- `nanobot/command/router.py` (`CommandRouter`, `CommandContext`)
- `nanobot/command/builtin.py` (`cmd_*`, `register_builtin_commands`)
