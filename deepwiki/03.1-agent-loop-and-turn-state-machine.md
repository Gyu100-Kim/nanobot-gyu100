# 3.1 Agent Loop and Turn State Machine (에이전트 루프와 턴 상태 머신)

`nanobot/agent/loop.py`의 `AgentLoop`는 코어 처리 엔진이다. 인바운드 메시지를 받아, 히스토리·메모리·스킬로 컨텍스트를 만들고, 턴을 조율한다.

## 턴 상태 머신

턴은 명시적 상태 머신으로 진행된다. 상태는 `TurnState(Enum)`으로 정의된다.

```python
class TurnState(Enum):
    RESTORE  # 세션·워크스페이스 스코프 복원
    COMPACT  # 필요 시 컨텍스트 컴팩션
    COMMAND  # 슬래시 명령 인라인 처리
    BUILD    # 컨텍스트/메시지 빌드
    RUN      # AgentRunner 실행
    SAVE     # 세션 저장
    RESPOND  # OutboundMessage 조립·발행
    DONE
```

각 상태 전이는 `StateTraceEntry`(state, started_at, duration_ms, event, error)로 추적된다. 이는 관측성과 디버깅을 위한 것이다.

상태별 처리 함수(발췌):

- `_state_restore(ctx) -> TurnState` — 세션 로드/복원.
- `_state_compact(ctx)` — 유휴/과대 컨텍스트 컴팩션([4.3](04.3-consolidation-and-autocompact.md)).
- `_dispatch_command_inline(...)` — 슬래시 명령 처리([8.1](08.1-cli-commands-reference.md)).
- `_run_agent_loop(...)` — RUN 상태 본체, 러너 호출.
- `_assemble_outbound(...)` — 응답 메시지 조립.

## `TurnContext`

한 턴의 모든 가변 상태는 `@dataclass TurnContext`에 담긴다. 주요 필드:

- `msg`, `session_key`, `state`, `turn_id`, `session`.
- `history`, `initial_messages`, `all_messages` — 메시지 파이프라인.
- `final_content`, `tools_used`, `stop_reason`, `had_injections` — 결과.
- `on_progress`, `on_stream`, `on_stream_end`, `on_retry_wait` — 콜백.
- `hooks`, `tools` — 훅 목록과 도구 레지스트리.
- `pending_queue`, `pending_summary` — 지연 자동화/주입.
- `turn_wall_started_at`, `visible_run_started_at`, `turn_latency_ms` — 타이밍.
- `trace` — `StateTraceEntry` 목록.

## 생성과 초기화

- `AgentLoop.from_config(...)` — 설정으로부터 루프를 구성하는 팩토리.
- `__init__(...)` — 프로바이더 스냅샷, 도구 레지스트리, 세션 매니저, 메모리 스토어, cron 서비스 등을 배선.
- `_register_default_tools()` — 기본 도구를 레지스트리에 등록.
- `_connect_mcp()` — 설정된 MCP 서버 연결([6.2](06.2-web-search-and-mcp-tools.md)).
- `set_model_preset(name, ...)` / `model_preset` 프로퍼티 — 런타임 모델 프리셋 전환. `_build_model_preset_snapshot`, `_apply_provider_snapshot`, `_refresh_provider_snapshot`로 프로바이더 스냅샷을 갱신.

## 메인 루프

- `run()` — 버스에서 인바운드를 소비하는 상시 루프.
- `_dispatch(msg)` — 메시지를 시스템/일반으로 분기.
- `_process_message(...)` / `_process_system_message(...)` — 실제 턴 실행.
- `_schedule_background(coro)` — 백그라운드 태스크 스케줄.
- `stop()`, `close_mcp()` — 종료 처리.

## 자동화 턴

cron·트리거 같은 자동화도 같은 루프를 통과한다.

- `submit_cron_turn(msg)` / `submit_local_trigger_turn(msg)` — 자동화 진입.
- `pending_cron_job_ids_for_session`, `pending_local_trigger_ids_for_session`, `_publish_next_deferred_automation_turn` — 세션이 바쁠 때 지연 큐 처리. 세부는 [8.2](08.2-gateway-runtime-and-background-services.md).

## 훅 (`nanobot/agent/hook.py`)

훅은 턴 수명주기의 각 지점을 관측/변형하는 확장점이다. 베이스는 `AgentHook`이며 `CompositeHook`이 여러 훅을 묶는다.

수명주기 콜백: `before_run`, `before_iteration`, `on_stream`, `on_stream_end`, `before_execute_tools`, `emit_reasoning`/`emit_reasoning_end`, `after_iteration`, `after_run`, `on_error`, `on_finally`, `finalize_content`.

- `SDKCaptureHook` — SDK 실행에서 결과를 캡처([10.2](10.2-python-sdk.md)).
- `_SubagentHook` — 서브에이전트 진행 추적([3.4](03.4-sub-agents-and-parallel-execution.md)).
