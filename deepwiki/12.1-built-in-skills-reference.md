# 12.1 Built-in Skills Reference (내장 스킬 레퍼런스)

`nanobot/skills/` 아래의 각 디렉토리가 하나의 내장 스킬이다. `nanobot/skills/README.md`의 표를 기준으로 정리한다.

|---|---|---|
| `github` | `nanobot/skills/github` | `gh` CLI로 GitHub과 상호작용 |
| `weather` | `nanobot/skills/weather` | wttr.in / Open-Meteo로 날씨 조회 |

## 스킬과 도구의 관계

스킬은 **절차적 지식**(무엇을·언제·어떻게 할지)이고, 도구는 **실행 능력**이다. 여러 스킬은 특정 도구의 올바른 사용법을 안내한다.

- `long-goal` ↔ `long_task` 도구와 세션 목표 상태([4.1](04.1-session-manager.md), [6.3](06.3-cron-image-generation-and-other-tools.md)).
- `cron` ↔ `cron` 도구와 `CronService`([8.2](08.2-gateway-runtime-and-background-services.md)).
- `image-generation` ↔ `image_generation` 도구([6.3](06.3-cron-image-generation-and-other-tools.md)).
- `memory` ↔ 메모리 파일과 Dream([4.2](04.2-memory-store-and-dream-system.md)).
- `my` ↔ `my`/runtime 도구([6.3](06.3-cron-image-generation-and-other-tools.md)).

## 항상 로드되는 스킬

`memory`와 `my`는 `get_always_skills`(`nanobot/agent/skills.py`)에 의해 관련성과 무관하게 항상 컨텍스트에 포함된다. 이는 에이전트가 언제나 기억을 관리하고 자기 상태를 점검할 수 있어야 하기 때문이다([3.3](03.3-context-builder-and-system-prompts.md)).

## 새 스킬 만들기

1. `skill-creator` 스킬의 안내에 따라 워크스페이스에 스킬 디렉토리와 `SKILL.md`를 만든다.
2. frontmatter에 `name`, `description`을 채우고 본문에 절차를 쓴다.
3. 다음 턴에 `SkillsLoader`가 자동으로 발견한다.
4. 공유하려면 `clawhub`로 레지스트리에 게시할 수 있다.

### 참조 파일

- `nanobot/skills/README.md`
- `nanobot/skills/<skill>/SKILL.md`
- `nanobot/agent/skills.py` (`SkillsLoader`, `get_always_skills`)
