# 6.3 Cron, Image Generation, and Other Tools (Cron·이미지 생성·기타 도구)

## Cron 도구 (`nanobot/agent/tools/cron.py`)

`CronTool` (`cron`)은 에이전트가 미래/반복 작업을 예약하게 해준다. 실제 스케줄링은 게이트웨이의 `CronService`(`nanobot/cron/service.py`)가 담당한다([8.2](08.2-gateway-runtime-and-background-services.md)).

- 작업 추가/목록/삭제를 지원.
- 스케줄은 cron 표현식 또는 상대 시간(예: `every 30m`)으로 지정.
- 예약된 잡이 발화하면 자동화 턴으로 에이전트 루프에 들어간다(`AgentLoop.submit_cron_turn`).
- 리마인더 템플릿: `nanobot/templates/agent/cron_reminder.md`.

## 이미지 생성 도구 (`nanobot/agent/tools/image_generation.py`)

`ImageGenerationTool` (`image_generation`)은 텍스트 프롬프트로 이미지를 생성한다.

- `ImageGenerationToolConfig`(`tools.imageGeneration`)로 프로바이더/모델을 설정.
- 실제 생성은 `nanobot/providers/image_generation.py`의 프로바이더(OpenRouter, AiHubMix, Ollama, Gemini, MiniMax 등)가 수행([5.2](05.2-anthropic-azure-bedrock-and-specialized-providers.md)).
- 생성된 이미지는 미디어 디렉토리(`get_media_dir`)에 저장되고, 채널로 전송될 수 있다.

## Spawn 도구 (`nanobot/agent/tools/spawn.py`)

`SpawnTool` (`spawn`)은 서브에이전트를 백그라운드로 위임한다. 상세는 [3.4 Sub-agents and Parallel Execution](03.4-sub-agents-and-parallel-execution.md).

## Long Task / Sustained Goal (`nanobot/agent/tools/long_task.py`)

지속 목표(long-goal) 도구는 여러 턴에 걸쳐 계속되는 장기 작업을 관리한다. 세션 메타데이터의 목표 상태(`nanobot/session/goal_state.py`)와 연동하며, 러너의 `goal_active_predicate`/`goal_continue_message`가 목표가 살아있는 동안 자동으로 다음 반복을 유도한다([3.2](03.2-agent-runner-and-llm-provider-interface.md)). 내장 `long-goal` 스킬이 이 흐름을 안내한다([12.1](12.1-built-in-skills-reference.md)).

## Message 도구 (`nanobot/agent/tools/message.py`)

`MessageTool` (`message`)은 에이전트가 채널로 능동적으로 메시지를 보내게 해준다(예: 다른 채팅으로 알림, heartbeat 결과 전송). 채널/대상 지정을 위해 컨텍스트를 인식한다.

## Self / Runtime 도구 (`nanobot/agent/tools/self.py`, `runtime_state.py`)

`MyTool` (`my`)은 에이전트가 자기 자신의 런타임 상태를 조회·조정하게 해준다.

- `MyToolConfig`로 설정.
- `_format_status(...)` — 현재 모델, 서브에이전트 진행(`SubagentStatus`), 세션·워크스페이스 정보 등을 렌더링([3.4](03.4-sub-agents-and-parallel-execution.md)).
- `runtime_state.py` — 런타임 상태 스냅샷 헬퍼.

내장 `my` 스킬이 이 도구의 사용법을 안내하며 항상 로드되는 스킬 중 하나다([3.3](03.3-context-builder-and-system-prompts.md)).

## CLI Apps 도구 (`nanobot/agent/tools/cli_apps.py`)

`CliAppsToolConfig`(`tools.cliApps`)로 설정되는 도구로, 특정 CLI 애플리케이션을 통제된 방식으로 실행한다.
